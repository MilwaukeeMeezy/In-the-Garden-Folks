# Grow Where You Live

A privacy-first garden planning prototype for urban and small-space growers. Explore sun and shade by time of day, log soil tests, simulate rain runoff, match native plants to each bed, and track seasonal pests.

This prototype is part of **In the Garden, Folks!** — *Grow Where You Live.*

## Try it

Open `index.html` in any modern browser. It's a single HTML file with no build step and no outside requests.

To publish it using GitHub Pages:

1. Open this repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.

## Privacy

- Optional cookies are off by default. Nothing is stored until the visitor turns an option on.
- No analytics, advertising pixels, outside fonts, or third-party scripts are included.
- The prototype does not request camera, microphone, photo-library, or device-location permissions.
- Photos are chosen one file at a time; location metadata inside them is removed.

## Accessibility

- Required descriptions for photos; descriptions or transcripts and optional caption files for video.
- Text size, higher contrast, and reduced-motion settings.
- Text versions of maps and keyboard-operable controls.
- Accessibility target: WCAG 2.2 AA.

## Status

**Working prototype, not a production-ready service.** The demo yard is fictional, demo weather and pest sightings are example data, and there are no user accounts yet.

The privacy and accessibility descriptions above document the prototype's intended behavior and should be independently tested before a public launch.
